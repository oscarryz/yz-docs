# `break`/`continue`/`return` in loops

`YZC-0019`

**`break` in a `while` body compiles and has no effect.** `return` and `continue` in a loop were not tested for this ticket.

concurrency model settled; parser/sema/lowerer work is self-contained. Depends on: YZC-0031.

Re-run on 2026-10-30 with `yzc` built from `ccebf83`: a `while` body ending in `break` ran all 3 iterations.
