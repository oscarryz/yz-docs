# Array `<<` append

`YZC-0013`

**`a << item` fails at `go build`: it lowers to `a.Ltlt`, and the runtime has only `Array.Append`.**

`a << item` → `a.Append(item)`; `Array.Append` exists in yzrt. Depends on: YZC-0031.

Re-run on 2026-10-30 with `yzc` built from `ccebf83`: `a.Ltlt undefined (type rt.Array[rt.Int] has no field or method Ltlt)`.
