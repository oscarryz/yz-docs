# Option/Result method chaining

`YZC-0014`

**Option and Result have no `or_else` or `and_then`.** Neither name appears in the compiler or the runtime as of `ccebf83`.

`result.or_else({ error Error; ... })`, `result.and_then({ val T; ... })`. Depends on: YZC-0031.
