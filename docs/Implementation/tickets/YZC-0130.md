# Docs are not checked by okf-check

`YZC-0130`

**This repository is okf-check's first consumer.** okf-check is a standalone OKF checker.[^brief]
Once it is released, the whole repository is one bundle, gated at `block: house` by a GitHub
Actions workflow, with the same result locally. The counts below were taken on 2026-11-06. Run
okf-check at `block: none` first to get the full list.

## What to do

1. **Gate.**
   - Add a workflow that fetches the pinned okf-check release with a committed SHA-256, and runs it.
     The same script runs locally.
   - Add `.okf-check.yaml` with `version` and `block: house`.
   - Neither Go nor `compiler/go.mod` is involved.
2. **Index front matter (spec §8).**
   - In the root index,[^root-index] `--fix` replaces the front matter with `okf_version: "0.2"`.
   - `spec/index.md`[^spec-index] loses its front matter entirely, so `spec/` does not become a
     separate bundle.
3. **Actors (spec §7).** 327 `generated.by` values (321 flow style, 6 block style) and 2 `verified.by`
   values are a bare `"oscarryz"`. Map them with `--fix --actor oscarryz=human:oscarryz`. The two
   verified ones then read as human-reviewed, which is correct only because a person did review them.
4. **Logs (spec §9).**
   - `docs/Implementation/log.md` has 18 headings with a suffix, such as `## 2026-09-28 (6)`.[^impl-log]
     Removing the suffix leaves several groups with the same date, so merge them. Whether okf-check
     reports a repeated date group is not decided yet; merging is valid either way.
   - `docs/log.md`[^docs-log] and `spec/log.md`[^spec-log] have no date headings at all.
5. **READMEs.** `compiler/README.md`[^readme] and `compiler/examples/multi_root/README.md` lose their
   whole front matter. Front matter with `generated` but no `type` is reported as `missing-type`.
   After the fix, the root index's link to `compiler/README.md` also points at a file that is not a
   concept, which is reported, so drop or keep that link knowingly.
6. **Index rows.** Two documents in `docs/Examples/` are missing from its index.[^examples]
7. **Descriptions.** okf-check checks index descriptions against each document's `description`.
   Expect about 300 findings.

## When

okf-check's Stage 1, by **2027-02-19**. The `--fix` cases for index front matter and `--actor`
ship in that same stage.
